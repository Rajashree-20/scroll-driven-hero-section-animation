# Scroll-Driven Hero Section Animation

A scroll-driven hero section built for a frontend animation assignment.

## Tech stack

- HTML / CSS
- JavaScript / TypeScript
- React
- Next.js
- Tailwind CSS
- GSAP + ScrollTrigger

## Features

- Above-the-fold hero layout
- Letter-spaced headline
- Staggered initial-load animation
- Statistics revealed one by one
- Scroll-linked visual movement
- Smooth scrubbed GSAP animation
- Transform-based motion
- Sticky hero viewport for a controlled scroll experience
- Responsive desktop and mobile layout
- GitHub Pages deployment workflow

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Build

```bash
npm run build
```

The static output is created in `out/`.

## GitHub Pages

Use this repository name:

```text
scroll-driven-hero-section-animation
```

Push the project to the `main` branch.

In GitHub, open:

**Settings → Pages → Source → GitHub Actions**

The included workflow handles the deployment.
